# Loja de Informática e Administração de Estoque
---

Esse é um projeto final desenvolvido no âmbito da disciplina de Programação Orientada a Objetos, visando aplicar todos os conceitos e práticas aprendidas durante o percurso do ensino. 

O contexto do software está diante da realidade das dificuldades enfrentadas por pequenos negócios relacionados a assistencias técnicas de informática. Diante disso, apresentamos uma solução voltada para a administração, gerenciamento e centralização desses serviços, promovendo ao empreendor acompanhar as vendas, clientes e relatórios gerenciais.
